# API DevOps

**Definice a role API**
- zkratka pro Application Programming Interface
- vystupuje jako softwarový prostředník umožňující dvěma aplikacím nebo komponentám vzájemně komunikovat
- klíčová součást moderního softwarového stacku

## Strategie vývoje API

**Code-first přístup**
- primární zaměření na implementaci kódu, z něj následně odvozena definice rozhraní
- často u jednoduchých nebo interních služeb

**Design/Contract-first přístup**
- nejdříve dochází k definici kontraktu (specifikace)
- určuje pravidla komunikace ještě před samotným psaním kódu
- umožňuje paralelní vývoj na straně poskytovatele i konzumenta rozhraní

## Specifikace API

**Standardizace komunikace**
- využití pro přesnou definici datových formátů a dostupných operací rozhraní
- standardy pro REST API, které jsou základem pro moderní mikroslužby

**Položky specifikace**
- endpointy, parametry (v cestě/query) a akce (GET, POST, ...)
- hlavičky, tělo, odpovědi

**OpenAPI**
- formát pro popis REST API (formát JSON nebo YAML)
- nejpoužívanější a nejoblíbenější, strojově čitelná
- možnost generování klienta, serveru i dokumentace
- poslední verze 3.1

**Swagger**
- umožňuje zkoušení jednotlivých volání API
- generuje se z OpenAPI dokumentace

## Životní cyklus a DevOps

- verzování a životní cyklus jako u softwaru
- komplexní správa rozhraní od počátečního návrhu přes vývoj a testování až po nasazení a případné vyřazení
- automatizace testování a nasazování rozhraní v rámci CI/CD pipeline

**Monitoring API**
- sledování dostupnosti, doby odpovědi, správnosti odpovědi a řešení chyb
- dlouhodobé metriky o stavu API

## API brány (Gateways)

- centrální vstupní bod pro komunikaci s vnitřními komponentami systému
- klíčový prvek pro distribuované aplikace a cloud-native řešení

**Funkce**
- autentizace a autorizace, ACLs, tokeny
- integrace s bezpečnostními službami
- směrování požadavků na backendy
- zajištění správy provozu
