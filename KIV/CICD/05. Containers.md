# Kontejnery a pokročilé koncepty

**Historie a typy virtualizace**
- 1999 – uvedení VMware Workstation 1.0
- 2003 – vznik XEN
- 2007 – nástup Virtual Boxu
- 2008 – uvedení Windows Hyper-V

**Typy virtualizace**
- **nativní** typu 1 (bare metal) běžící přímo na hardwaru
- **hostovaná** typu 2 běžící nad operačním systémem

## Principy kontejnerizace

- mechanizmus izolace zdrojů v jádře
- kontrola využití zdrojů
- bezpečnost (snížení práv roota)

**Implementace kontejnerů**
- LXC (Linux Containers)
- Docker (platforma)
- Windows Containers
- Podman (daemon-less Docker alternativa)

**Open Container Initiative** (OCI)
- projekt Linux Foundation
- standardy pro kontejnerové formáty a technologie
- 3 specifikace (runtime, image a distribution)

## Docker

- docker daemon, který spravuje kontejnery
- kontejnery sdílí operační systém (jádro), ale mají vlastní knihovny a procesy
- správa základních prvků
	- obrazy (images)
	- datové svazky (volumes) pro persistenci
	- sítě (networks) pro komunikaci

**Docker image**
- obraz souborového systému kontejneru
- identifikován hashem, jménem a tagem (např. postgres:15.1)
- vrstvená architektura – na sebe se vrství změny nad původním obrazem

### Pokročilé koncepty

**Vícefázové sestavování (multistage builds)**
- primární cíl v podobě udržení co nejmenší velikosti výsledného obrazu
- optimalizace počtu vrstev v souborovém systému kontejneru, například spojováním více příkazů RUN do jednoho (rozdíl mezi 3 vrstvami a 1 vrstvou)
- oddělení **sestavovacího prostředí** (obsahující zdrojový kód a build tools) od **finálního obrazu** obsahujícího pouze spustitelné artefakty
- využití mezilehlých artefaktů během procesu sestavování pro vyšší efektivitu

**Monitorování kontejnerů**
- možnost tvorby healthchecků
	- kontrola, jestli kontejner správně funguje
- `docker stats` – využití zdrojů kontejnerem

**Správa aplikací pomocí Docker Compose**
- nástroj pro definici a správu komplexních aplikací složených z více microservices
- řízení celého životního cyklu aplikace
	- spouštění, zastavování a opětovného sestavování služeb
	- možnost streamování logů z více kontejnerů najednou
	- vizualizace stavu běžících služeb
- koncept "lepidla" na úrovni kontejnerů
	- propojuje malé služby do jednoho funkčního celku (stacku)

**Pokročilé operace a analýza**
- techniky pro testování a průběžné monitorování kontejnerů v produkčním prostředí
- možnosti a postupy pro škálování služeb (service scaling) podle aktuální zátěže
- provádění hloubkové analýzy složení kontejnerů (composition analysis)
